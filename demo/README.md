# Demos

Whole applications built with `odf`, closer to a real business than the
[examples](../examples/), which each show one concept. A demo uses most of
ODF at once and runs with `docker compose up`.

| Demo | What it shows |
|---|---|
| [`bakery/`](bakery/) | A bakery's existing tools (a café POS, a business messenger, email, spreadsheets on a shared drive) joined up by an `odf` project: webhooks, a polled mailbox, a watched drive and a scheduler bring everything into one place. Agents react to what arrives and draft order changes, price renegotiations and allergen notices for a person to confirm, and the UI, chat and MCP all work on the same model of the business. |

The businesses, people and data in the demos are fictional.
